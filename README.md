# 실시간 익명 채팅방

수강생이 로그인 없이 들어와 익명으로 글을 남기는 채팅 화면입니다.
HTML · CSS · 순수 JavaScript + supabase-js 하나로 만들었고, Vercel 에 정적 사이트로 올립니다.

## 저장하지 않습니다
- 글은 Supabase **실시간 방송(Broadcast)** 으로 지금 접속한 사람끼리만 주고받습니다.
- 표 · SQL · DB 저장이 없습니다. Supabase 설정에서 할 일도 없습니다.
- 늦게 들어온 사람은, 이미 방에 있는 사람 화면에서 최근 글 50개를 넘겨받습니다.
- 방에 아무도 없으면 이전 글은 사라집니다.

## 파일
| 파일 | 하는 일 |
|---|---|
| index.html | 화면 구조 |
| style.css | 디자인 (어두운 남색 + 하늘색) |
| app.js | 보내기 · 받기 · 지우기 · 화면 상태 6종 |
| config.js | Supabase 주소 + 공개용(anon) 키 두 줄. 비밀 키 금지 |

## 쓰는 법
- 배포 주소로 들어옵니다. 내 PC 에서는 index.html 을 더블클릭해도 됩니다.
- 반을 나누려면 주소 뒤에 방 코드를 붙입니다. 예: `https://주소/?room=A1B2C3`
  - 영문 · 숫자 · `-` · `_` 1~20자, 대문자로 바뀝니다. 없으면 `MAIN` 방.
- 입력칸 왼쪽 동그라미(이름표)를 누르면 닉네임을 바꿉니다. (30자, 비우면 "익명")
- Enter 로 보내고, Shift+Enter 로 줄을 바꿉니다. 메시지는 500자까지.

## 화면 상태 미리보기
주소 뒤에 `?demo=상태` 를 붙이면 가짜 데이터로 각 상태를 볼 수 있습니다.
`loading`(로딩) · `empty`(0건) · `ready`(정상) · `offline`(실패) · `noserver`(연결 도구 없음)

## 확인 방법
| 번호 | 할 일 | 기대 결과 |
|---|---|---|
| C-01 | 빈 방 열기 | 초록 점 "실시간 연결됨", 할 수 있는 것 / 알아 둘 것 안내 카드 |
| C-02 | 창 두 개(또는 폰)로 같은 방 열고 한쪽에서 보내기 | 새로고침 없이 양쪽에 바로 뜸, 인원 2명 |
| C-03 | 글이 있는 방에 세 번째 창으로 들어오기 | 이전 글이 보임 |
| C-04 | "👍 이해했어요" 버튼 누르기 | 바로 보내짐. 3초 안에 또 누르면 "방금 같은 글을 보냈어요" |
| C-05 | 내 글 "지우기" → 4초 안에 "되돌리기" | 글이 남음. 안 누르면 모든 화면에서 사라짐 |
| C-06 | 닉네임 바꾸기 | "이제 ‘○○’ 이름으로 보여요" + 되돌리기 |
| C-07 | 위로 스크롤한 상태에서 다른 사람이 글 쓰기 | "새 글 1개 ↓" 버튼 |
| C-08 | 인터넷 끊고 보내기 | 빨간 띠 + 다시 연결, 내 글에 "다시 보내기" |
| C-09 | `<b>굵게</b>` 보내기 | 태그가 글자 그대로 보임 |

## 알아 둘 점
- 주소를 아는 사람은 누구나 들어올 수 있습니다.
- 도배를 막으려고 한 기기에서 5초에 5개까지만 보냅니다. (화면에서만 막음)
- 내 글은 보낸 기기에서만 지울 수 있습니다. 강사가 남의 글을 지우는 기능은 없습니다.
- 강의 PDF 는 `.gitignore` 로 GitHub 에 올리지 않습니다.
